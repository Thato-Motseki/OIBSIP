# Java Task 4 - Online Examination System

A Java Swing-based online examination system.

## Features
- Username/password login screen
- Profile update before the exam
- Display name and password fields
- Multiple-choice questions with four options
- Next and Previous navigation
- Visible countdown timer
- Automatic submission when time reaches zero
- Manual submission confirmation
- Results showing score, correct/incorrect answers, and time taken
- Logout from results
- Window-close confirmation while the exam is active

## Run
```bash
javac src/*.java
java -cp src Main
```
